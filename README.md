> [!NOTE]
> Please use a white or light terminal for best experience with the translucent logo.


Sunet theme for [presenterm](https://github.com/mfontanini/presenterm).

Make sure the install/rsync/copy the directories in to your [configuration directory](https://mfontanini.github.io/presenterm/configuration/introduction.html).

Apply by `--theme sunet` or
```
theme:
  name: sunet
```
